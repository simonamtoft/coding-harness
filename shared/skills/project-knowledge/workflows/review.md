# Review and update actions and questions

## Show what is open

Read the **Open** tables in `context/actions.md` and `context/questions.md`. Answer with what was asked, for example open items for one owner, items past their due date, or questions raised before a date. Quote ids so the user can refer to them. Do not reorder or reformat the files to answer a question.

## Change an item

Only the register changes; meeting notes stay as written.

- **Done or answered:** move the row from Open to Closed. Fill Outcome or Answer, and set `Closed in` to the meeting note or source that settled it, or to `user YYYY-MM-DD` when the user just told you.
- **Dropped:** move it to Closed with Outcome `dropped: <reason>`.
- **Owner or due date changed:** edit the row in place and add `YYYY-MM-DD: <old value> -> <new value>` to Notes.
- **New item outside a meeting:** append a row under Open with the next id and `Raised in` set to `user YYYY-MM-DD` or the source file.

Report each id you changed and how.
